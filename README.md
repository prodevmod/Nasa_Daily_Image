# About this Project
This is a product of the stardance's program "Give Your Website a Pulse" mission.It is a vite powered website that displays the days nasa's image of the day along with a title and a description, utilising the NASA free personalised API token.

I made a website using HTML,CSS a little bit of JS, Vite and the Nasa API which shows you nasa's image of the day along with a title and it's description.It contains 2 image hyperlinks: 1 for NASA official website and the 2nd one redirects you to the stardance program's website whose quide helped me make this project.I also added a glowing cursor effect and custom fonts imported from google. 
The site is devided in 2 main screens: The loading screen and the image of the day screen.The site is programmed to catch errors so it does't just crash but outputs a message to the user.As stated previously it uses the NASA's free APOD API.

Through this project I learned how the git workflow works, how a website or script comunicated with an API and basics of JS.I also grasped a little better the Vite structure and function.
